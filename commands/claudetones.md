# /claudetones — Manage Claudetones audio playback and soundpacks

Control acoustic awareness sounds in Claude Code across Desktop & Terminal.

## Usage
- `/claudetones` — Toggle mute
- `/claudetones pause` — Pause sound playback
- `/claudetones play` — Resume sound playback
- `/claudetones stop` — Stop currently active sound
- `/claudetones status` — Show current playback and mute status
- `/claudetones test [event]` — Test an audio cue (e.g. web_search, mcp_connect, skill_invoke, done)
- `/claudetones log` — Inspect recent playback, collision drops, and preemption logs
- `/claudetones clear-log` — Clear the local telemetry log
